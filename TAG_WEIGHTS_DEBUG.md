# Tag Weights Display - Debug Fix

## Issues Reported

1. **Tag weights showing same values for all images**
   - User reports that images 0, 1, 2, 3 all show the same concept weights (from image 0)
   - This suggests the image index parsing is failing

2. **Tags not turning colors after clicking**
   - Some tags are not responding to clicks (not turning green/red)
   - This may be a separate issue from tag weights

## Fix Applied

### Enhanced Image ID Parsing

Added comprehensive debugging and support for multiple ID formats:

```javascript
// Before: Only handled 'round_X_image_Y' and 'image_Y'
// After: Also handles 'impression_refinement_X_Y' format

const parts = imageId.split('_');
let roundNum = refinementRound;
let imageIdx = 0;

if (parts[0] === 'round') {
  // Format: round_1_image_0
  roundNum = parseInt(parts[1]);
  imageIdx = parseInt(parts[3]);
} else if (parts[0] === 'image') {
  // Format: image_0
  imageIdx = parseInt(parts[1]);
} else if (parts.includes('refinement')) {
  // Format: impression_refinement_0_0
  const refinementIdx = parts.indexOf('refinement');
  if (refinementIdx >= 0 && parts.length > refinementIdx + 1) {
    imageIdx = parseInt(parts[refinementIdx + 1]);
  }
}
```
